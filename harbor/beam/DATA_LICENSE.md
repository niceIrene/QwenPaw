# BEAM data attribution

The conversation data, public probing questions, held-out rubrics, and
reference answers in this directory are derived from **BEAM: Beyond a Million
Tokens: Benchmarking and Enhancing Long-Term Memory in LLMs** by Mohammad
Tavakoli, Alireza Salemi, Carrie Ye, Mohamed Abdalla, Hamed Zamani, and J. Ross
Mitchell.

- Upstream repository: <https://github.com/mohammadtavakoli78/BEAM>
- 10M dataset: <https://huggingface.co/datasets/Mohammadta/BEAM-10M>
- Paper: <https://arxiv.org/abs/2510.27246>

The BEAM benchmark data is licensed under the Creative Commons
Attribution-ShareAlike 4.0 International License:
<https://creativecommons.org/licenses/by-sa/4.0/>.

The QwenPaw/Harbor packaging and runner code does not change the underlying
benchmark data license. Redistributions and adaptations of the task data must
retain attribution and use a compatible share-alike license.
